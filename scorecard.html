The "finishes past" odds came true about as often as they said. The "gets there" odds were first set at a flat 2x the finish odds; that ran too high near price (said 87%, happened 61%), so the board now uses a corrected version (shown here). The correction was fitted on this same sample, so the live scorecard will be its real test. Short sample: one wild autumn.
